# Verstak

ИИ-помощник для работы с кодом на Windows.

**Скачать:** https://agi-iri.ru/verstak/

Этот репозиторий содержит только официальные сборки. Через него работает
автообновление установленного приложения: клиент читает `latest.yml` из
последнего релиза и скачивает установщик оттуда же.

Исходный код закрыт и в этом репозитории не публикуется.
