# AGENTS.md — указатель на регламент проекта Verstak

> **ПОЛНЫЙ РЕГЛАМЕНТ ЖИВЁТ В `CLAUDE.md`. ПРОЧИТАЙ ЕГО ЦЕЛИКОМ ПЕРЕД РАБОТОЙ.**
> Здесь намеренно нет ни карты архитектуры, ни состава фич, ни команд: всё, что
> продублировано в двух файлах, однажды разъедется — и победит тот файл, который
> читается, а не тот, который правят.

## Почему этот файл такой короткий

`electron/ai/user-layer.ts` ищет правила проекта по списку
`AGENTS.md → CLAUDE.md → GEMINI.md → .verstak/RULES.md` и **останавливается на
первом найденном** (`user-layer.ts:74`, `break`). В этом репозитории есть оба
файла, поэтому в system prompt агента уходил только `AGENTS.md`, а `CLAUDE.md` не
читался никогда.

Цена этого выяснилась 30.07. Прежняя версия файла была майским снимком,
испорченным слепой заменой «Claude» → «Codex» (`~/.Codex/skills/`, `Codex.ts`,
порядок поиска «AGENTS.md → AGENTS.md»), и несла ложную норму «8 sqlite-тестов
падают по `NODE_MODULE_VERSION` — это ожидаемо». Норму признали ложной и удалили
из `CLAUDE.md` ещё коммитом `14f46e1`, но чистка прошла по файлу, который не
читается. Так агент внутри продукта — и Павел, когда работает над Verstak из
самого Verstak, — получал прямое разрешение списать красный прогон на шум.

Поэтому тело файла вынесено, а не переписано: указатель разъехаться не может.

## Что нельзя потерять, даже если до `CLAUDE.md` дело не дошло

Полный список — `CLAUDE.md` **§3.1 «Правила исполнителя»**; каждая его строка
стоила потерянного дня. Абсолютный минимум:

- **Полный гейт после каждой задачи, без сокращений:** `check:mojibake` →
  `lint:full` (0 errors) → `type` → `test:fast` (0 падений, полнота сверена с
  эталоном `EXPECTED_TOTAL_TESTS`) → `build` → `check:performance` →
  `git diff --check`.
- **Шума в тестах НЕТ: любое падение — регрессия.** Массовые падения по
  `NODE_MODULE_VERSION` означают открытое приложение Verstak (оно держит
  `better_sqlite3.node`) — это условие прогона, а не свойство кода.
- **Никогда `git add -A` и `git commit -a`** — в рабочем дереве бывает чужая
  незакоммиченная работа.
- **Хрупкая зона:** подписка `ai.onEvent` в `src/components/Chat.tsx` ставится
  ОДИН раз за жизнь экрана; её пересоздание теряет события молча, без падений и
  красных тестов. Не трогать.
- **Сначала тест, воспроизводящий дефект, потом фикс**, и обязательная мутация
  фикса — иначе пин декоративный.
- **Фикстура обязана совпадать с ПРОДОВОЙ формой вызова.** Тест на входе,
  которого в проде не существует, не защищает ничего и об этом не сообщает.
  Рядом с пином «действие НЕ произошло» обязан стоять кейс, где оно ПРОИСХОДИТ.
- **Закрывая позицию, снимай запись о её отсутствии ТЕМ ЖЕ КОММИТОМ.** Запись,
  пережившая свою правду, опаснее отсутствия записи: тесты прозу не проверяют, а
  следующий читатель принимает её за факт и строит на ней решение. За 29–30.07
  таких нашлось шесть, и дважды они прямо направили постановку задачи — перечень
  и разбор в `CLAUDE.md` §3.1.
