# Verstak — браузерный сотрудник

Расширение связывает выбранную вкладку Chrome или Edge с обычным AI-чатом
Verstak. Модель читает безопасный снимок страницы, а действия выполняются через
единый BrowserController с проверкой прав, подтверждением человека и readback.

## Как подключить

Пока расширение не опубликовано в Chrome Web Store, один раз загрузите его как
unpacked:

1. Откройте `chrome://extensions` и включите режим разработчика.
2. Нажмите **Load unpacked** и выберите папку `browser-extension` из поставки
   Verstak.
3. В Verstak откройте **Настройки → Интеграции → Браузер** и нажмите
   **Подключить браузер**.
4. На нужной странице нажмите значок Verstak. Откроется боковая панель, а именно
   эта вкладка подключится автоматически.
5. Дайте задачу в обычном чате Verstak или в поле боковой панели.

Pair-код, ручной Attach и копирование JSON в рабочем сценарии не нужны.
После первой локальной авторизации расширение хранит закрытую пару и ограниченно
восстанавливает соединение после перезапуска Verstak. Вкладку после обрыва нужно
выбрать снова значком расширения: незавершённое действие само не повторяется.

## Границы доступа

- Native Messaging Host `ru.verstak.browser_bridge` работает локально и не
  открывает публичный сетевой порт.
- Manifest разрешает подключение только стабильному extension id Verstak.
- Первичная пустая авторизация разрешается лишь в коротком одноразовом окне,
  открытом кнопкой в настройках; постоянный credential не отдаётся страницам UI.
- Расширение работает только с вкладкой, выбранной нажатием на его значок.
- Для текущей вкладки используется `activeTab`; постоянный доступ запрашивается
  только к конкретному origin, без `<all_urls>`.
- Снимок содержит видимый текст, таблицы и карту доступных элементов. Значения
  форм, пароли, cookies, storage, скрытые и editable-области не читаются.
- Модель получает непрозрачный `elementRef`, а не CSS, JavaScript или CDP.
- Изменяющее действие выполняется один раз после scoped approval и сверяется с
  новой версией страницы. Неизвестный результат остаётся `uncertain`.
- DOM и снимки страницы передаются только провайдеру, разрешённому политикой
  данных выбранного клиента; fallback проверяется до передачи истории.

## Текущий пользовательский контур

Рабочая вертикаль: подключение вкладки → чтение страницы → ответ в чате →
подтверждённый клик → повторное чтение результата. Публикация в Chrome Web Store
остаётся отдельной задачей распространения; до неё единственный ручной шаг —
первичная загрузка unpacked-расширения.
