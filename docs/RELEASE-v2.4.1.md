# Verstak 2.4.1 — агент сам работает с сайтами

## Что вы получаете

**Агент сам открывает сайты и работает со страницей.** Попросите открыть сайт —
агент откроет его сам, вкладку «Браузер» открывать не нужно. Он видит страницу
списком пронумерованных элементов, кликает и вводит текст по номеру, дожидается
загрузки — может пройти сценарий и заполнить форму. Откроете вкладку «Браузер» —
увидите ту же страницу, которой управляет агент.

Вкладка «Браузер» открывается пустой и сразу готова к работе.
