# Open Design #3 — Live Artifacts: одна страница для Павла (это его решение)

Штаб не решает — продуктовое, несёт Павлу. Здесь: что человек получит, чего стоит,
с чем пересекается. (Полный разбор источника — `docs/task9-open-design-research-2026-08-04.md`.)

## Что это
Сейчас артефакты Verstak (generate_html / render_chart) — СТАТИЧНЫЕ: сгенерировали один
раз, данные застыли. Live Artifact — артефакт, который МОЖНО ОБНОВИТЬ по кнопке: шаблон
+ источник данных → пересборка. Пример: дашборд клиента из Я.Метрики/Директа/Ozon, который
не переделываешь руками каждую неделю, а жмёшь «Обновить» — и цифры свежие.

## Что человек получит
- Живые отчёты/дашборды клиента поверх наших 31 read-only коннектора (Метрика, Директ,
  Ozon, WB, amoCRM, МойСклад…): собрал раз — обновляешь кнопкой, отдаёшь клиенту ссылку.
- Аудит обновлений (кто/когда/что тянул) — это ДНК нашего Proof Pack, ложится на edge
  «контроль/прозрачность»: клиент видит, что цифры настоящие и откуда.
- Встроенное превью уже есть — Live Artifact открывается там же.

## Чего это стоит (честно)
- Не одна кнопка: нужен формат шаблона (безопасный — у OD это `{{data.path}}` БЕЗ JS/raw
  HTML, чтобы артефакт не стал дырой), связка «шаблон+данные+рендер», хранение и версии.
- Обновление должно быть fail-closed (битый рефреш НЕ обнуляет артефакт), с локом и
  таймаутом — иначе клиент увидит пустой отчёт. Это аккуратный слой, не хак на вечер.
- Оценка грубо: MVP (один коннектор-источник + html-шаблон + рефреш+аудит) — ~5–8 дней;
  полноценно (несколько источников, снапшоты, расписание) — фазами дальше.

## С чем пересекается
- **Наша headless/облачная линия** (её ведёт штаб): рефреш по расписанию и серверный
  рендер логично живут там же, где демон. НЕ строить второй контур — свести с headless.
- **Задача 8 (расписание)** и **Open Design #13 (automation-proposals)**: авто-обновление
  Live Artifact по расписанию — тот же механизм.
- **Proof Pack**: аудит рефрешей переиспользует идею доказательства прогона.

## Рекомендация исполнителя (не решение)
Высокая продуктовая ценность и точное попадание в edge Verstak (контроль/прозрачность +
RU-коннекторы, которых у западных нет). Но это ВЫБОР НАПРАВЛЕНИЯ продукта и большой слот —
поэтому Павел. Если «да» — начинать MVP на ОДНОМ коннекторе, свести с headless-линией,
формат шаблона брать безопасный (без JS), обновление fail-closed с аудитом.
