## Быстрый старт и плавный ответ

**Меньше ожидания до первого ответа.** Независимые части контекста проекта загружаются параллельно. CLI-промпт собирается один раз: Debug Packet получает фактически отправленный payload от провайдера, а не запускает вторую дорогую сборку.

**Плавный стрим.** Мелкие текстовые и мыслительные дельты объединяются в одно обновление состояния на кадр. Параллельные чаты не смешиваются, terminal event синхронно сбрасывает хвост перед завершением.

**Быстрее первый экран.** Вторичные разделы, настройки проекта, side-chat и preview вынесены в lazy chunks. Главный renderer entry уменьшен с 1 772 517 до 1 534 911 байт (−13,4%). Регрессия скорости теперь блокируется: после production build проверяется бюджет главного chunk.

## Память проекта перестала быть свалкой

Раньше агент писал в память строку на каждую запись файла и запуск команды («Записан файл X, 123 символов»), а в конце сессии — её пересказ целиком, до 2000 символов. Такие записи вытесняли из подсказок настоящие факты о проекте.

Теперь память пополняется в двух точках и только по делу:

- **перед сжатием контекста** из уходящей части диалога забираются принятые решения, устойчивые факты, незакрытые долги и важные ошибки;
- **в конце сессии** сохраняется короткий итог.

Пачка ограничена по количеству и длине, секреты вырезаются до записи, повторное событие не создаёт дубликат, а сбой извлечения не может помешать сжатию или завершению прогона. Сырой автозахват выключен по умолчанию и возвращается настройкой `auto_capture_memory`.

## Что вошло из продуктовой волны 2.1.x

- **2.1.8 Паспорт результата** — экспорт любого Outcome-прогона в Markdown через системный Save As, с редакцией секретов и путей.
- **2.1.7 Центр вмешательств** — durable jobs, где нужен человек: остановленные после сбоя, заблокированные, ожидающие решения.
- **2.1.6 История результатов** — экран «Прогоны»: история переживает перезапуск и открывает старый прогон без повторного запуска модели.
- **2.1.5 «До результата»** — один вход в управляемое выполнение задачи с целью, ограничениями, критерием готовности и глубиной.
- **2.1.4 Model Gym** — воспроизводимая Arena для одинаковых fixture-задач через Verstak, Codex CLI и OpenCode.

## Под капотом

Продолжена декомпозиция агентного рантайма: маршрут `ai:send` (выбор провайдера и модели, pre-flight подписочного аккаунта, fallback), бухгалтерия прогона и IPC управления прогоном вынесены в отдельные модули. Поведение, публичные IPC-контракты и порядок событий не менялись.
