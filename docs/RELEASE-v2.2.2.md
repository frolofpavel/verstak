# Verstak 2.2.2 — чистый старт и честная готовность

## Сразу пишите задачу

Новый чат больше не предлагает сначала выбрать Marketing, Writing, Code или
другого «агента». Эти роли не меняли возможности Verstak, но создавали лишний
экран и впечатление, что для каждой работы нужен отдельный режим.

Теперь на старте остаются:

- вопрос **«Что нужно сделать?»**;
- широкое поле ввода;
- привычные настройки модели и режима работы.

Напишите задачу обычными словами — Verstak сам использует доступные инструменты.

## Коннекторы показывают реальную готовность

Пустая или неполная настройка больше не выглядит как готовое подключение.
Состояние коннектора формируется по фактической конфигурации, а авторизованный
вызов проверяется на реальном пути выполнения.

## Экономнее работа через CLI

Правила проекта передаются CLI-модели один раз за ход. Раньше большой регламент
мог повторяться в истории и занимать контекст без пользы.

## Настройки поведения стали видимыми

Runtime-флаги собраны в **Настройки → Поведение агента**. Можно увидеть, какие
механизмы памяти, проверки и исполнения включены, не разыскивая локальные
конфигурационные файлы.

## Надёжность

Исправлены нестабильные тесты CLI и lazy-loading. Внутренние крупные модули чата
и запуска агента продолжили разбивать на понятные части — без изменения
поведения готовых функций.
