# Model Gym Arena — методика 2.1.4

Arena сравнивает coding-runner-ы на одинаковых детерминированных fixture-задачах. Это
инженерный измерительный контур, а не публичный рейтинг и не рекламное обещание.

## Команда

```bash
npm run eval:arena -- --runners verstak,codex,opencode --models provider/model --suite core --repeat 3
```

Отчёты пишутся в `.verstak-data/model-gym/` и не попадают в Git. Для узкого
smoke используются `--tasks small-edit,bugfix`. `--dry-run` проверяет контракт
без сетевых запросов и учётных данных.

## Правила сопоставимости

1. Один commit Verstak, один fixture, один model id и одинаковый timeout.
2. Каждый повтор выполняется в новом временном Git-workspace.
3. Runner получает только права на запись в этот изолированный workspace.
4. Успех определяется fixture-командами `verify`, а не текстом ответа модели.
5. Версии runner-ов фиксируются в отчёте.
6. Если модель, non-interactive automation или permission profile нельзя
   выровнять, запуск получает `comparable=false` и не участвует в рекомендации.
7. Производственная рекомендация запрещена при числе повторов меньше трёх.
8. Сохраняются pass rate, медиана времени, доступная оценка стоимости и число
   вмешательств. Неизвестная стоимость остаётся `unknown`, а не нулём.
9. Секреты не записываются в JSON/Markdown. Конкурентным runner-ам не передаются
   gateway/API переменные Verstak.

README-ссылка и любые публичные выводы добавляются только после отдельного
решения владельца и живого воспроизводимого прогона.
